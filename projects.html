Vitre OS

A 64-bit operating system in pure x86-64 assembly that rewrites itself while it runs: edit a kernel function in its own editor and it is patched in live, with rollback if it crashes. Desktop, sound, video, TCP/IP, TLS 1.3 and a web browser, and not one line of C.

#assembly #x86-64 #nasm #qemu

tuxmedic

A terminal app that finds what is wrong with a Linux desktop and says it in plain words: crashes, Wi-Fi, sound, screens, battery and 30 checks in all, each with the command that fixes it on your distro. Works on any distro and any terminal size, without root.
